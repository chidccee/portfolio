Студентка четвёртого курса направления «Информационная безопасность». Развиваюсь в ручном тестировании программного обеспечения, функциональном тестировании веб-приложений и подготовке тестовой документации.

## Проекты по тестированию

### [Ручное тестирование SauceDemo](manual-qa-saucedemo/README.md)

Полный учебный проект ручного тестирования интернет-магазина:

- область тестирования и тестовые предположения;
- чек-лист из 32 проверок;
- 12 подробных тест-кейсов;
- результаты тестового прогона;
- воспроизводимый баг-репорт;
- итоговый отчёт о тестировании.

## Проекты по программированию и информационной безопасности

### MyVim

Текстовый редактор на Python с модульными и интеграционными тестами на `pytest`. Проверяются операции со строками, загрузка и сохранение файлов, поиск, история команд, `undo/redo` и изменение состояния приложения.

### Рефакторинг и тестирование Sudoku

Игра Sudoku на Python. Логика приложения разделена на компоненты; тестами проверяются игровое поле, допустимые и недопустимые ходы, решение головоломки и переходы между состояниями игры.

### Защищённый crackme

Учебный проект на C/C++ для изучения анализа и защиты программной логики: проверки целостности, обфускация и механизмы противодействия анализу.
