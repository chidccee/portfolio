# Итоговый отчёт о тестировании

## Краткое резюме

9 сентября 2026 года выполнено ручное функциональное тестирование приоритетных сценариев SauceDemo. Основной путь пользователя `standard_user` от входа до обзора заказа работает без блокирующих дефектов. Для пользователя `problem_user` найден воспроизводимый визуальный дефект каталога.

## Покрытые функции

- авторизация с корректными и некорректными условиями;
- отображение каталога;
- сортировка по возрастанию цены;
- добавление товара и переход в корзину;
- проверка обязательности имени;
- переход к обзору заказа;
- проверка состава и арифметики заказа;
- отображение карточек для проблемного пользователя.

## Риски и ограничения

- Тестирование проводилось в одном desktop-окружении.
- Не проверялись мобильная версия и другие браузеры.
- Не выполнялось тестирование API, производительности, безопасности и доступности.
- Часть кейсов оставлена со статусом `Not run`, чтобы отделить подготовленную документацию от реально выполненного прогона.
- Тестовая сессия использовала общее состояние браузера; поэтому значение счётчика проверялось как изменение относительно исходного состояния, а не как гарантированное абсолютное значение.

## Рекомендация

Основной сценарий можно продолжать тестировать. Перед выпуском приложения для проблемной конфигурации следует исправить BUG-01 и провести повторную проверку изображений. Для следующей итерации рекомендуется выполнить оставшиеся тест-кейсы, добавить мобильное окружение и проверить граничные значения полей оформления.
