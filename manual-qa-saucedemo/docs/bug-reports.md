# Баг-репорты

## BUG-01 У всех товаров отображается одинаковая заглушка изображения

| Поле | Значение |
|---|---|
| ID | BUG-01 |
| Заголовок | В каталоге у пользователя `problem_user` изображения всех товаров заменены одинаковой заглушкой |
| Окружение | SauceDemo, desktop browser, macOS, 9 сентября 2026 года |
| Предусловие | Открыта форма входа |
| Серьёзность | Major |
| Приоритет | High |
| Воспроизводимость | 100%, 1/1 |
| Статус | New |

Шаги воспроизведения:

1. Открыть `https://www.saucedemo.com/`.
2. Войти как `problem_user` с паролем `secret_sauce`.
3. Открыть каталог `Products`.
4. Сравнить изображения всех шести карточек с названиями товаров.

Фактический результат: у всех карточек отображается одинаковая заглушка; путь изображения содержит `/assets/sl-404-...jpg`.

Ожидаемый результат: каждая карточка отображает уникальное изображение, соответствующее названию товара.

Влияние: пользователь не может визуально различать товары; снижается понятность каталога и доверие к интерфейсу.

Примечание: дефект привязан к специальному тестовому пользователю `problem_user` и не воспроизводится в основном сценарии `standard_user`.
