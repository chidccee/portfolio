# Чек-лист

Обозначения: `P` — проверка пройдена, `F` — обнаружен дефект, `NT` — не выполнялась в текущем прогоне.

## Авторизация

| ID | Проверка | Приоритет | Статус |
|---|---|---:|:---:|
| AUTH-01 | Вход с корректными данными `standard_user` | Высокий | P |
| AUTH-02 | Вход с пустыми логином и паролем | Высокий | P |
| AUTH-03 | Вход с пустым логином | Средний | NT |
| AUTH-04 | Вход с пустым паролем | Средний | NT |
| AUTH-05 | Вход с неверным логином | Высокий | NT |
| AUTH-06 | Вход заблокированного пользователя | Высокий | P |
| AUTH-07 | Маскирование введённого пароля | Средний | NT |
| AUTH-08 | Выход из учётной записи | Высокий | NT |

| CAT-03 | Сортировка по названию A–Z | Средний | NT |
| CAT-04 | Сортировка по названию Z–A | Средний | NT |

| CAT-06 | Сортировка по цене по убыванию | Средний | NT |
| CAT-07 | Переход в карточку по названию товара | Средний | NT |
| CAT-08 | Переход в карточку по изображению товара | Средний | NT |
| CAT-09 | Соответствие изображения названию товара для `problem_user` | Высокий | F |
