# Ручное тестирование веб-магазина SauceDemo

Портфолио-проект по ручному функциональному тестированию учебного интернет-магазина [SauceDemo](https://www.saucedemo.com/).

## Цель проекта

Проверить основные пользовательские сценарии интернет-магазина: авторизацию, каталог, сортировку, корзину и оформление заказа. Подготовить тестовую документацию и зафиксировать найденные дефекты.

## Объект тестирования

- Приложение: SauceDemo
- Тип приложения: веб-магазин
- Дата тестирования: 9 сентября 2026 года
- Окружение: desktop browser, macOS
- Тестовые пользователи: `standard_user`, `locked_out_user`, `problem_user`
- Тестовый пароль: `secret_sauce`

## Проведённые виды тестирования

- функциональное тестирование;
- позитивное и негативное тестирование;
- проверка обязательных полей;
- тестирование переходов между страницами;
- базовое UI-тестирование;
- исследовательское тестирование.

## Результат

- Подготовлен чек-лист из 32 проверок.
- Описано 12 подробных тест-кейсов.
- Фактически выполнено 10 приоритетных тест-кейсов: 9 пройдено, 1 завершён с дефектом.
- Найден и описан воспроизводимый визуальный дефект карточек товаров для пользователя `problem_user`.
- Критических блокирующих дефектов в основном сценарии пользователя `standard_user` не обнаружено.

## Основные проверенные сценарии

1. Вход с корректными учётными данными.
2. Обработка пустых и заблокированных учётных данных.
3. Отображение каталога из шести товаров.
4. Сортировка товаров по возрастанию цены.
5. Добавление товара в корзину и отображение счётчика.
6. Сохранение состава корзины при переходе к оформлению заказа.
7. Валидация обязательных полей формы покупателя.
8. Проверка состава заказа и итоговой суммы.
9. Проверка карточек товаров для пользователя с проблемным состоянием.

## Ограничения

Проект выполнен на общедоступном учебном стенде без доступа к требованиям, серверным журналам, базе данных и API. Часть ожидаемого поведения сформулирована как тестовые предположения и явно отмечена в документации.
